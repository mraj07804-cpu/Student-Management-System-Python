# Student Result Management System

## Objective

The Student Result Management System is a Python-based project designed to manage student records and calculate academic results automatically. The system stores student information, calculates total marks, percentage, and assigns grades based on performance.

---

## Features

- Add student records
- Store roll number and student name
- Record marks of multiple subjects
- Calculate total marks
- Calculate percentage automatically
- Generate grades (A+, A, B, C, Fail)
- Display complete student details
- Simple and user-friendly interface

---

## Technologies Used

- Python
- Object-Oriented Programming (OOP)

---

## Project Structure

### Student Class

The Student class stores:

- Roll Number
- Student Name
- Subject Marks

Functions:

- Calculate Total Marks
- Calculate Percentage
- Generate Grade
- Display Student Information

### Database Class

The Database class manages:

- Student Records
- Data Storage
- Record Retrieval

---

## Working

1. User enters student details.
2. Subject marks are stored in the system.
3. Total marks are calculated automatically.
4. Percentage is generated.
5. Grade is assigned based on percentage.
6. Student details are displayed.

---

## Grade Criteria

| Percentage | Grade |
|------------|--------|
| 90 and above | A+ |
| 75 - 89 | A |
| 60 - 74 | B |
| 50 - 59 | C |
| Below 50 | Fail |
